# 无人值守夜跑的规矩

写给夜里替我干活的 agent，也是早上我自己复核的清单。

核心前提：**这一夜没有任何真实环境验证** —— 红区只有人能进，而人在睡觉。
所以所有判据必须机器可判，"看起来对"一律不算数。

这份文件的第一要务不是拦你，是让你**敢干**。所以先讲你的职权，再讲边界。

## 边界

- **做**：v1 = 目标 1（批量扫描）+ 目标 2（结果归档）。阶段 P1–P6，见 `PROJECT_BRIEF.md` §12。
- **不做**：目标 3（接 SNP_RLC_Extractor 做批量对比）是 v2。

什么算范围长出来：workflow 表之外的新顶层功能、新的对外接口、新的顶层目录。
什么不算：实现所需的内部 helper、额外的测试、`scripts/dev_*` 之类的开发辅助。
**拿不准就做，然后在报告里报备 —— 漏报才是问题，做了不是。**

> ⚠️ `CLAUDE.md` 的状态行和 `PROJECT_BRIEF.md` §9a 写着"尚未写代码""那四块模块先别动"。
> 那是 2026-08-17 的状态，**已被 §12 实现计划取代 —— 今晚就是那个"谈完之后"**。
> 文件打架时以本文件和 §11/§12 为准。

## 你的职权

这份文件不可能覆盖一夜里的所有分叉。撞上没写到的情况时，原则只有一条：

> **红着交出来 + 说清楚，永远好过绿着但可疑。红不是失败，假绿才是。**

| 情况 | 怎么办 |
|---|---|
| BRIEF 有歧义或自相矛盾 | **不要停。** 选一个解释继续干，把「问题 / 两种读法 / 选了哪个 / 为什么 / 改判的代价」写进报告的「设计偏离」一节。BRIEF 本身不改 —— 它不进 git，你改了早上看不到 diff |
| 接口冻结后发现签名是错的 | **可以改**，但走流程：同一个 commit 改 `model.py` + `INTERFACES.md` + 全部调用方，message 标 `[interface-change]` 写明为什么，审查 agent 专门核对。**静默漂移才是禁止的，改一个错的冻结不是** |
| 某个判据无法机器化 | 写一个最接近的机器判据，在报告里写明它与原判据的差距。不许因为"验不了"就不验 |
| 「不许碰」清单**之外**的既有代码有 bug（`mvp/`、`scripts/` 都算） | **修**，commit message 单列一行说明。清单之外的一切都在你职权内，清单不是"只许碰新文件" |
| 同一个问题被审查打回两次还过不了 | 冻结这个子任务，状态写清楚，转去做不依赖它的部分。**不许用降低测试强度的方式让它过** |

**不需要请示、也不用记录理由的**：内部函数怎么拆、测试怎么组织、非冻结接口内的实现选择、
加辅助测试、往 `.gitignore` **增加**条目（新的运行产物、`*.local.*` fixture 等）。

**万一时间不够**：先保住 P1–P4 与部署链路可用。GUI 可以降级为「三版 frame 建得起来、
核心接线过 smoke，但交互未逐项验证」—— 但**必须写在报告第一行**。不许悄悄降级。

## 一票否决

```
sh scripts/check.sh
```

退出码就是判据。任何一项红 = 这个阶段没完成，不许进下一阶段。

**适用范围**：从 P1 起是每阶段的闸。Phase 0 的判据以 workflow 表里那一行为准
（能被 import + 签名覆盖 P1–P5），不套用 check.sh。

**关于 skip**：平台性 skip 允许 —— 比如本机没有某份 `*.local.*` fixture 时优雅跳过
（`check.sh` 第 1 步自己就是这么写的），但必须带一行原因，审查 agent 会逐条看。
**为了让闸门变绿而 skip 一条失败的测试**，那才是禁止的。

`check.sh` 自身在 2026-08-18 被验证过有牙：故意弄红一条测试，它确实报 RED。
（那次顺带修掉一个真洞：`cmd | tail || FAIL=1` 里管道退出码取自 `tail`，永远是 0，
否决权是空的。别改回去。）

## 防自证

无人监督时最大的风险不是跑不完，是**写出自己证明自己的测试**：实现方生成 argv，
又由实现方决定期望的 argv 是什么，于是测试全绿而命令是错的。

不是假想 —— MVP 里踩过一次：排除规则写 `--sparam` 前缀误伤了 `--sparamImpedance`，
两边同时被跳过，diff 空得非常好看，但根本没比。**空过的测试比没测更坏。**

### 三条原则

1. 期望值只能来自人抽取的 fixture，**不许在测试里现算期望值**。
2. 每条关键测试要有反向验证：故意改一个值必须被抓到。
3. 每个阶段后由独立审查 agent 复核，它不写代码，只放行或打回。

### 落到写法上的四条配方

1. **什么算「关键测试」**：任何断言「生成物（argv / 目录名 / 渲染出的模板 / 解析结果）
   等于某个期望值」的测试。内部 helper 的测试不算。
2. **反向验证的标准写法**：复制一份输入，故意改坏一个值（换个温度、删个 flag、改个 pin 名），
   断言比较逻辑**报告了这个差异**。它是一条独立测试，名字带 `_negative`，与正向测试成对出现。
3. **凡是比较逻辑里有「排除 / 忽略 / 前缀过滤」，过滤器本身要有测试**：断言它没把不该忽略的
   一起忽略掉（`--sparam` 误伤 `--sparamImpedance` 就是这条的缺失）。**外加一条计数断言**：
   实际参与比较的条目数 == 从 fixture 数出来的条目数。空集合 diff 永远是绿的 ——
   这条专防"空得非常好看"。
4. **审查 agent 的操作程序**（是动手，不是读报告）：
   1. 自己跑一遍 `sh scripts/check.sh`，**只认自己看到的退出码**；
   2. `git diff` 上一阶段，核对「不许碰」清单里的路径零改动、fixture sha 未变；
   3. `grep -rn "skip\|xfail" tests/`，每个命中要有一行原因；
   4. **挑两条关键测试，亲手把实现里对应的值改坏，跑测试确认变红，再改回来**；
   5. 核对每条关键测试有配对的 `_negative`；
   6. 结论只写「放行」或「打回 + 证据」，不写综述。

第 4 步是关键 —— 它把"测试真的在测东西吗"从一个态度问题变成一个动作。

## 不许碰

| 路径 | 为什么 |
|---|---|
| `tests/fixtures/production_cmd.local.json` | golden 期望值。改它 = 测试自己证明自己。整套防自证的锚 |
| `tests/fixtures/production_cmd.sha256` | 上一条的锁 |
| `references/` | 红区取回的证据，只读。改了 = 证据污染 |
| `PROJECT_BRIEF.md` | 设计权威，且**它不进 git —— 你改了早上看不到 diff** |
| `CLAUDE.md` 的硬约束段 | 项目宪法。（状态行的过期问题见「边界」节，不用你处理） |
| `.gitignore` 的红区段 | 唯一的泄漏防线。**增加**条目允许，动红区那几行才是禁区 |
| `mockups/` | 界面草图是设计成果，产品界面另开 `gui/`。起跑前已验证三个冒烟全绿；夜里若变红，**先怀疑你动过的公共环境**，确认是 mockups 自身 bug 时允许最小修复，报告单列 |
| `scripts/check.sh` | **只许朝更严的方向改**（新增检查、修 bug）；删除或弱化既有检查视同改 fixture。每次改动 commit message 单列，审查 agent 必须 diff 这个文件 |

## git

- **commit**：每阶段至少一个（返工可以多个），message 写清这阶段做了什么、`check.sh` 什么结果。
- pre-commit 闸门保持启用，不用 `--no-verify`。**闸门拦下你时，修内容，不修闸门。**
- **push：阶段中不推；全部完成后推一次。** 推之前当场满足四条：
  1. `sh scripts/check.sh` **当场跑**全绿，不引用早前的输出；
  2. 对**将要推出去的全部历史**补扫红区 —— 不只是工作区，中间 commit 里进过又删掉的字符串
     一样会被发布出去：`git log -p origin/main..HEAD` 的输出对着 `.redzone_patterns.local`
     加通用规则再 grep 一遍，零命中；
  3. 打印 `git remote -v` 和将推的 commit 列表，确认目标是 `weisbert/Ewave_helper`；
  4. 只推一次。失败（认证、冲突、任何原因）**不重试、不 force、不改凭据配置** ——
     把原因写进报告，commit 留在本地。**没推出去不算失败，推错了才是。**

## 环境事实（别浪费时间去试）

- 本机没有 `ewave` / `dsub` / `strmout`，**不可能**真跑。别写依赖它们的验证步骤。
- 目标机登录 shell 是 csh/tcsh，Python 3.11.4，**无装包权限** → 只用 stdlib。
- GUI 用 tkinter，import 必须惰性（无 `$DISPLAY` 的 ssh 会话里 CLI 要能用）。
- 源码零站点标识符。坐标靠**运行时发现**（解析官方 run 目录）或 site-local 配置。
- 任何含红区坐标的 fixture（P4 的日志样本也是）走 `*.local.*` 命名 + 不进 git +
  缺失时优雅 skip，照 `production_cmd.local.json` 的样子办。

## workflow 结构

阶段之间是硬依赖，只能串行；并行只发生在阶段内部。
**Phase 0 不许跳** —— 跳过接口冻结，并行的 agent 必然发明互不兼容的数据模型，
早上收到的会是一堆拼不起来的零件。

| Phase | 并行 agent | 产出 | 判据 |
|---|---|---|---|
| **0 接口冻结** | 1（串行） | `ewave_batch/model.py`：Design / Axis / Run / RunStatus / BatchState 的数据结构 + 跨模块函数签名 + docstring，**只写签名不写实现**；外加 `docs/INTERFACES.md` 一页 | 能被 import；签名覆盖 P1–P5 全部跨模块调用 |
| **1 核心** | 3 | `core/matrix.py` 展开+slug+varying 轴 · `core/cmd.py` 四层合并→argv · `core/layout.py` 目录/归档/state 读写 | `cmd.py` 对着 golden fixture 逐 flag 验，**且带反向验证与计数断言** |
| **2 阶段一** | 2 | `tools/strmout.py` 渲染 gdsout_setup 模板（D1c 那 8 个字段） · `core/discover.py` 从官方 run 目录解析坐标 | discover 用 `mvp/redzone/cfg.sh` 同款解析路径；纯字符串 → 单测 |
| **3 调度** | 2 | `sched/fake.py`（**先做**）· `sched/donau.py` 从 kit 移植 · `sched/driver.py` 两阶段 DAG + 有界并发 + poll + verify + archive + resume | FakeRunner 要模拟实测过的坑：`exit=0` 但崩了、0 字节产物报 done、写失败被吞。12-run 假批次全链路，含失败与 resume |
| **4 日志** | 1–2 | `core/logparse.py` → 收敛/墙钟/峰值内存/端口数/成败 | 用 MVP 取回的真实日志当 fixture（`*.local.*`） |
| **5 界面** | 3 | `cli.py`（run / dry-run / resume / archive / status）· `gui/`（共用层 + `frames/{stacked,tabbed,split}.py`，默认 split） | headless smoke 三版都建得起来；**无 `$DISPLAY` 时 CLI 必须可用** |
| **6 部署 + 收尾** | 2 | 见 `PROJECT_BRIEF.md` §12「部署方案」——**照抄 `C:\code\SNP_RLC_Extractor/deploy/`，形状必须一致** · 红区验证包 · 交接报告 | `pack.ps1` 打得出包且包内 `.sh` 是 LF；`doctor.sh` 三 tier 判定正确；完整 `check.sh` 全绿 |

**每个 Phase 后挂一个独立审查 agent**（共 6 名，不写代码），按「防自证 → 配方 4」的
六步操作程序执行。合计约 **21 个 agent**。

## 早上要交出来的东西

1. **已 push 的 `main`**（全绿之后推的那一次），以及 `git log` 一阶段一个 commit。
2. **首次部署指令** —— 一段可直接照着敲的操作，从黄区 `git pull` 到红区
   `bash deploy/doctor.sh --test`，含每一步的预期输出。
3. **红区验证包** —— 一条命令能拿去红区跑 dry-run，不用先读代码。
4. **交接报告** —— 每阶段做了什么、`check.sh` 结果、**哪些地方我没把握**、
   设计偏离（选了哪个解释、为什么）、红区第一次跑该看什么、失败了怎么办。

报告里「没把握的地方」必须写实。夜里没人拦着，写得漂亮没有意义，写得准才有意义 ——
而且「红着交出来」是合法的，所以诚实不花你任何代价。
